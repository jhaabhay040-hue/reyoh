# REOYH – Trusted Home & Online Tutor Marketplace

Static React + Vite + Tailwind frontend for showcasing a tutor marketplace concept.

## Stack
- React (Vite)
- Tailwind CSS
- React Router
- No backend / auth / database

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Structure
```text
src/
  components/
  pages/
  data/
  App.jsx
  main.jsx
```
